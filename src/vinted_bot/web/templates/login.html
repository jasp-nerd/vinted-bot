{% if from_env and container %}

It's the VINTED_BOT_WEB_AUTH_TOKEN setting in the environment: section of the container's docker-compose.yml, or in the app's settings in a NAS app store. Look it up there, or change it and run docker compose up -d (a plain restart keeps the old one).

{% elif from_env %}

It's the VINTED_BOT_WEB_AUTH_TOKEN setting on the computer running vinted-bot (in its environment or its .env file). Look it up there, or change it and restart.

{% elif container %}

On the machine running the container, in the folder with its docker-compose.yml, run docker compose exec vinted-bot vinted-bot reset-password. From a NAS app store, open the container's console there and run vinted-bot reset-password. It prints a new password and signs every browser out.

{% else %}

On the computer running vinted-bot, open a terminal and run vinted-bot reset-password. It prints a new password and signs every browser out.
